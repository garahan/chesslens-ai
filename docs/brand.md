# ChessLens identity — 0.13

The mark combines a simplified knight and four lens corners. Forest (#263f32), warm ivory (#fff8e8), and a restrained brass accent (#cdb98b) keep it connected to a classic chess set. The mark stays consistent across themes; interface accents follow the selected palette.

The header uses a compact wordmark with an outlined AI badge. The same SVG serves the favicon, header and theme previews. Home Screen exports are 180, 192 and 512 pixels, with opaque forest backgrounds and the artwork inside the mask-safe central area.

Interface icons use the Lucide family at 1.8px stroke weight, predominantly 18–20px. Buttons retain 44px minimum touch targets. Primary actions use the theme accent with a subtle inset edge; secondary actions use neutral surfaces and clear borders. Utility actions stay quiet, with separate hover, keyboard focus, pressed and disabled states. Board flip uses directional arrows; history/reset keep conventional navigation symbols and desktop tooltips.

The icon source is public/icons/icon.svg. PNG exports are rasterized from that vector, with a full-background fill before export. No remote font or icon service is required. Existing speed improvements, themes, sounds and offline behavior are retained.
